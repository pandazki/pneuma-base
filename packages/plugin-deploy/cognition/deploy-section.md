## 上线：主人开关

这个库装了**部署**插件。你做了能上线的东西，比如一个网站目录，放进库之后声明它可以部署：

```sh
pneuma-base @{{授权的名字}} say deployable sites/shop
```

声明不会让它上线。上不上线由主人用开关决定，你开不了；也不要自己把它部署到别处，要上线就告诉主人。开关开着的东西，线上跟着库里：新内容放到同一个路径，线上换成新的；挪了位置，换成新路径的站点；归档了，就下线。`inspect` 说它在线、离线还是待发布，地址是什么；`check` 列出线上还不是当前内容的，`pneuma-base @{{授权的名字}} deploy sync` 再对一遍。
