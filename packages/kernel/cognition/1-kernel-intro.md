# Pneuma Base 资料库

此文件夹是 Agent 与所有者共用的资料库和制品库，也是 Agent 自己的持久化空间：检索到的资料、所有者提供的资料和生成的成果都添加到此处，之后从此处检索。更换目录、会话或 Agent 后，资料库中的条目仍然保留。所有者拥有此资料库，Agent 是主要的读写者。

## 使用场景

- 本次任务要产出成品：资料、调研、方案、文档、设计，以及网站、页面、小工具等生成的成果。
- 所有者要求修改以前的成果，提到「以前做过的」「上次的」「库里」，或只给出一句缺少上下文的话。

在已有代码仓库中修改代码、回答临时问题时不使用。

## 命令

使用 `pneuma-base @{{授权的名字}} <命令> …`。`@{{授权的名字}}` 已绑定此资料库和 Agent 的身份，可在任意目录下直接使用，无需其他参数。它是约定的身份，不是密码。授权名称记录在技能文件中。

| 操作 | 命令 |
| --- | --- |
| 检索以前的资料和成果 | `pneuma-base @{{授权的名字}} find <关键词>` |
| 查看条目的全部已知信息（不含内容本身，内容直接读取文件） | `pneuma-base @{{授权的名字}} inspect <库内路径>` |
| 添加外部文件或整个目录（例如一个网站） | `pneuma-base @{{授权的名字}} put <外部文件或目录> --to <库内路径> --imported 或 --generated` |
| 直接添加一段内容 | `… \| pneuma-base @{{授权的名字}} put - --to <库内路径> --imported 或 --generated` |
| 在资料库内移动 | `pneuma-base @{{授权的名字}} put <库内旧路径> --to <库内新路径>` |
| 归档不再使用的条目 | `pneuma-base @{{授权的名字}} archive <库内路径>` |
| 资料库状态 | `pneuma-base @{{授权的名字}} check` |
| 所有者在管理界面中看到的任意页面 | `pneuma-base @{{授权的名字}} show` 列出各页，`show <页面 ID>` 打开一页，只读 |

`put` 时注明来源：导入（`--imported`，网页、文档、所有者提供的文件）或生成（`--generated`，Agent 生成的成果）。库内路径由 Agent 安排，按便于日后检索的方式命名和分文件夹。

添加的目录中有一个 `.pneuma-item` 标记，整个目录算作一个条目：检索、查看、移动、归档都按整体进行，目录内的文件不单独添加、移动或归档。修改时，将整个目录拷贝到外部修改（拷贝出的 `.pneuma-item` 无需删除），再整个目录一起 `put`，同名时按下文的规则处理。`.git`、`node_modules` 不会被添加。

归档的条目不会删除，而是移动到 `_archive/`。默认检索不包含已归档条目，`find --include-archived` 才包含；`unarchive <路径>` 取消归档。废弃的成果、不可行的方案、过时的草稿都应归档，不与使用中的条目混在一起。
