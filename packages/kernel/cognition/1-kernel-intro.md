# 这是一个 Pneuma Base 库

这个文件夹是你和主人共用的资料库和制品库，是你自己的地方：你找到的、主人给你的资料，你做出来的成果，都放这里；下次要用，从这里找。换了目录、换了会话、换了别的 agent，这里的东西都还在。主人是这个库的主人，你是主要的读写者。

## 什么时候用

- 这次要做出一样成品：资料、调研、方案、文档、设计，也包括一个网站、一个页面、一个小工具这样做出来的东西。
- 主人要你改一样以前做的东西，提到「以前做过的」「上次的」「库里」，或者只说了一句没头没尾的话。

在一个已有的代码仓库里改代码、回答一个随口的问题，不用它。

## 命令

用 `pneuma-base @{{授权的名字}} <动词> …`。`@{{授权的名字}}` 已经绑定了这个库和你的身份，在任何目录下直接用，不需要别的参数。它是约定的身份，不是密码。你的授权名在你的技能文件里。

| 你想做的 | 命令 |
| --- | --- |
| 找以前的资料和成果 | `pneuma-base @{{授权的名字}} find <文字>` |
| 看关于一样东西知道的一切（不含内容本身，内容你自己读文件） | `pneuma-base @{{授权的名字}} inspect <库内路径>` |
| 把库外的文件，或一整个目录（比如一个网站）放进来 | `pneuma-base @{{授权的名字}} put <库外的文件或目录> --to <库内路径> --brought 或 --made` |
| 把一段内容直接放进来 | `… \| pneuma-base @{{授权的名字}} put - --to <库内路径> --brought 或 --made` |
| 在库里挪位置 | `pneuma-base @{{授权的名字}} put <库内旧路径> --to <库内新路径>` |
| 不用了，归档 | `pneuma-base @{{授权的名字}} archive <库内路径>` |
| 库的状况 | `pneuma-base @{{授权的名字}} check` |

`put` 时说明它是带进来的（`--brought`，网页、文档、主人给的文件）还是你做出来的（`--made`）。库内路径随你安排，按以后好找的方式起名和分文件夹。

放进来的目录里会有一个 `.pneuma-item` 标记，整个目录算一样东西：找、看、挪、归档都按整体，它里面的文件不单独放、挪、归档。要改就把整个目录拷到库外改好（拷过去带的 `.pneuma-item` 不用删），再整个目录一起 `put`，同名时按下面的规矩。`.git`、`node_modules` 不会放进来。

归档的东西不删，挪进 `_archive/`。以后默认找不到它，`find --include-archived` 才带上；`unarchive <路径>` 取回。做废了的东西、走不通的方案、过时的草稿都归档，别让它们混在还在用的东西里。
