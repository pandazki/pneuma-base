# Pneuma Base

所有者为 Agent 提供了一个资料库，位于 `{{库的路径}}`。它是 Agent 自己的资料库和制品库，跨目录、跨会话、跨 Agent 保留。

**先读取 `{{库的路径}}/PNEUMA-BASE.md`。** 规则以该文件为准。

本机的 `pneuma-base` 命令为 `{{命令}}`，不一定在 PATH 中。资料库说明和答复中出现 `pneuma-base` 的地方，均用此完整路径运行。

三个步骤，可在任意目录下直接运行，无需先 `cd` 到资料库，也无需将路径存入变量：

```sh
{{命令}} @{{授权的名字}} start "<任务描述>"   # 返回资料库的变化和相关的已有条目
{{命令}} @{{授权的名字}} find <关键词>        # 继续检索；用 inspect <库内路径> 查看来源
{{命令}} @{{授权的名字}} put <外部文件或目录> --to <库内路径> --generated --from <依据的库内路径…>
```

不覆盖或删除资料库中已有的条目，不再使用的条目用 `archive` 归档。密钥和凭证不添加到资料库。
