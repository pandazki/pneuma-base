# Pneuma Base

主人给了你一个库，在 `{{库的路径}}`。它是你自己的资料库和制品库，跨目录、跨会话、跨 agent 都在。

**先读 `{{库的路径}}/PNEUMA-BASE.md`。** 规矩都在那里，以它为准。

记住三步，在任何目录下都能直接用：

```sh
pneuma-base @{{授权的名字}} start "<一句话：这次在做什么>"   # 库会告诉你有什么变化、有什么相关的旧东西
pneuma-base @{{授权的名字}} find <文字>                      # 再找找；用 inspect <库内路径> 看来历
pneuma-base @{{授权的名字}} put <库外的文件> --to <库内路径> --made --from <依据的库内路径…>
```

不要覆盖或删除库里已有的东西，不用了就 `archive`。密钥和凭证不放进库。
