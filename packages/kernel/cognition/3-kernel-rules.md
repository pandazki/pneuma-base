## 添加什么，不添加什么

添加：交付给所有者的成果；支撑结论的资料原文或摘录；所有者明确做出的决策。

不添加：

- 密钥、凭证、`.env`、所有者未要求保留的个人隐私。
- 已在代码仓库中的项目代码。资料库中添加一份说明：仓库位置、提交和使用方法。
- 临时草稿和一次性脚本，除非以后会再次使用。

此资料库中的条目，所有获得授权的 Agent 均可查看。关于所有者本人的简短事实归 Agent 自己的记忆；资料、成果、决策归资料库。

## 规则

- **不直接覆盖或删除资料库中已有的条目，不再使用的条目归档。** 新内容在外部写好再 `put`，不使用 Agent 自身的文件写入工具在资料库中写入、修改或删除文件。
- {{同名时怎么办}}
- 不修改 `.pneuma-base/` 中的任何内容。配置、插件、授权和清理由所有者负责。
- 没有 `pneuma-base` 命令时：将文件直接添加到资料库中即可，无需其他操作。

需要所有者执行管理操作时，用 `ask` 写明原因并附上命令，例如 `pneuma-base @{{授权的名字}} ask "Codex 也需要使用此资料库" grant create codex --agent codex`。所有者批准后按原样运行，结果显示在下次 `check` 的请求部分中。
