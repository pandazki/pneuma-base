## 什么值得放，什么不放

放：交付给主人的成果；支撑结论的资料原文或摘录；主人明确做出的决定。

不放：

- 密钥、凭证、`.env`、主人没让你留的个人隐私。
- 已经在某个代码仓库里的项目代码。库里放一份说明：仓库在哪、哪个提交、怎么用。
- 临时草稿和一次性的小脚本，除非以后会再用。

这个库里的东西，所有拿到授权的 agent 都看得到。关于主人本人的短事实归你自己的记忆；资料、成果、决定归库。

## 规矩

- **不要直接覆盖、删除库里已有的东西，不用了就归档。** 新内容在库外写好再 `put`，不要用你自己的写文件工具写、改、删库里的文件。
- {{同名时怎么办}}
- 不要动 `.pneuma-base/` 里的任何东西。配置、插件、授权、清理是主人的事。
- 没有 `pneuma-base` 这个命令时：把文件直接放进库里就行，别的不用做。
