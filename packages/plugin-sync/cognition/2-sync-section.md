## 同步：和另一处保持一致

这个库装了**同步**插件。它和主人设的同步目标双向同步，跑一次 `sync now` 同步一次，不在后台跑。它只整份地复制文件，从不合并内容：

- 两边改了同一个文件：本地的留在原处，另一边的那份放在旁边，叫 `<名字>.conflict-<机器>-<时刻><扩展名>`，`check` 会列出它。看过两份，把要的内容放回原文件，再把冲突副本归档。
- 另一边删掉或换掉的东西，别处没有副本的，留在 `_archive/` 里。主人用会丢数据的命令删掉的除外：两边都删掉。

```sh
pneuma-base @{{授权的名字}} sync status   # 目标、上次同步、待同步的数目、冲突副本
pneuma-base @{{授权的名字}} sync now
```
