# Agent icons

from the npm package `@lobehub/icons-static-svg`, version 1.106.0 (https://github.com/lobehub/lobe-icons),
unchanged except that the width and height attributes of the root element were removed. The product
names and marks are trademarks of their owners; their use here identifies the products and implies no
