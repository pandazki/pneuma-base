## 找：按正文和按意思

这个库装了**查找**插件。`find` 也在文本文件的正文里找（目录条目里的文件也算），按相关度排，每条命中带一小段上下文；中文按词匹配，两个字的词也找得到。主人配了嵌入器时，还可以用一句话描述要找的东西，没有原词也可能找到，这样的命中标着「按意思」。嵌入器和它的密钥是主人在自己的机器上配的，不用你管；按意思找没做成时，`find` 照常按文字给命中并说明原因，需要时告诉主人。超过 1 MB 的文件只找它的前 1 MB。

```sh
pneuma-base @{{授权的名字}} find 退款 流程
pneuma-base @{{授权的名字}} search status   # 配没配嵌入器
```
