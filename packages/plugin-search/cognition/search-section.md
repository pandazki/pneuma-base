## 搜索：全文检索与语义检索

此资料库已启用**搜索**插件。`find` 也在已登记的文本文件的全文中检索（目录条目中的文件也包括在内），按相关度排序，每条结果附带一段上下文；中文按词匹配，两个字的词也能检索到。所有者配置 embedding 后，还可以用一句描述检索，不含原词也可能命中，此类结果标有「语义」。embedding 服务及其密钥由所有者在本机配置，Agent 无需处理；语义检索失败时，`find` 照常返回全文检索结果并说明原因，需要时告知所有者。超过 1 MB 的文件只检索前 1 MB，超过 5000 个文件的目录条目不检索。启用搜索插件前已登记的条目，补录完成后才能检索全文；补录未完成时，`find` 的结果中有一行说明补录进度和继续补录的命令。

```sh
pneuma-base @{{授权的名字}} find 退款 流程
pneuma-base @{{授权的名字}} search status   # 是否已配置 embedding
```
